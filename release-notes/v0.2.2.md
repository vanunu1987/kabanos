Fixes the app icon in Spotlight, Finder and System Settings.

- The small sizes of the app icon (used by Spotlight, Finder lists and System Settings) were corrupted and showed scrambled pixels; the icon is now rebuilt from the full-resolution artwork with every standard size, including Retina
- If Spotlight still shows the old icon after updating, run `killall Dock; killall Finder` in Terminal to refresh macOS's icon cache

**Install:** download `kabanos-mac-arm64.dmg` (Apple silicon) or `kabanos-mac-x64.dmg` (Intel). This build isn’t notarized yet: on first launch open System Settings → Privacy & Security → Open Anyway.
