Index templates behave like templates again — and you can create new ones.

- Clicking a template while an index is open in the Index view now opens the template page (patterns, priority, settings, mappings) instead of treating it like a queryable index
- New: create index and component templates with the + button on their sections, starting from a ready-made JSON body
- A template tab left open from before shows a short notice with an “Open template” button

**Install:** download `kabanos-mac-arm64.dmg` (Apple silicon) or `kabanos-mac-x64.dmg` (Intel). This build isn’t notarized yet: on first launch open System Settings → Privacy & Security → Open Anyway.
