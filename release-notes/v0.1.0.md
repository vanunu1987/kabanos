The first public release of kabanos — a native Mac client for Elasticsearch and OpenSearch.

- Aggregation pipeline builder: stack stages, see each stage’s output, switch to JSON or ES|QL any time
- Edit alias targets and index template mappings right from the explorer
- Light mode, a menu-bar icon and a properly named app
- Saved connections with Basic, API key, Cloud ID, AWS SigV4, custom CA, certificate pinning, SSH tunnels and proxies — secrets in the macOS Keychain
- Explorer for indices, data streams, aliases and templates; index view with document editing and point-in-time paging
- Query workspace with named request blocks, mapping-aware autocomplete and Kibana / cURL import
- Searchable query library with folders, pins, #tags, history and environments
- Routines with variables, captures, assertions, polling and dry runs
- Mapping editor with generated reindex routines; stack management for Elasticsearch security and the OpenSearch Security plugin
- Export to JSON, NDJSON or CSV; read-only mode and production confirmations

**Install:** download `kabanos-mac-arm64.dmg` (Apple silicon) or `kabanos-mac-x64.dmg` (Intel). This build isn’t notarized yet: on first launch open System Settings → Privacy & Security → Open Anyway.
