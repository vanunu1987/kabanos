Small improvements to the query workspace and the aggregation builder.

- Delete a request block straight from its header — even when it's folded (saved queries stay in the library; unsaved ones ask first)
- Autocomplete now offers whole query objects when you start a new array element, e.g. `"must_not": [` → `{ "exists": { "field": … } }`
- Exclude filters in aggregation pipelines: not one of, not between, does not contain and does not exist — all compiled to `must_not`

**Install:** download `kabanos-mac-arm64.dmg` (Apple silicon) or `kabanos-mac-x64.dmg` (Intel). This build isn’t notarized yet: on first launch open System Settings → Privacy & Security → Open Anyway.
