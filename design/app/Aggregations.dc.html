Elasticsearch aggregations are a tree, not a list. Each Group by stage opens a new level and every later stage nests inside it, so the pipeline view reads top to bottom.
The same pipeline as an ES|QL query. ES|QL is piped, so each line is one stage. Requires Elasticsearch 8.11+; on OpenSearch this view switches to PPL.
FROM listings-v7
1| WHERE status == "active" AND price <= 2000000
3| STATS avg_price = AVG(price), median_price = MEDIAN(price),
sellers = COUNT_DISTINCT(seller_id), doc_count = COUNT(*)
2 BY city.name
5| WHERE avg_price > 1500000
6| SORT avg_price DESC
6| LIMIT 5
Note Stage 4 (group by month inside each city) can't be expressed in a single ES|QL STATS, so it is left out here. Turn stage 4 off, or keep using the JSON view.
